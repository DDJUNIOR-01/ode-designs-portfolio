# ODE Designs Portfolio

A ready-to-run Next.js portfolio for David Emenike / ODE Designs.

## Run it

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Customize

- Main page: `app/page.jsx`
- Styling: `app/globals.css`
- Images: `public/images/`
- Site metadata: `app/layout.jsx`

The portfolio uses the uploaded Webdev9ja designs as the selected work.
